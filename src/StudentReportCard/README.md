# 🎓 Student Report Card System (Java)

A simple **Java Console-Based Student Report Card System** that allows users to enter student details, subject names, and marks, then automatically calculates the total marks, percentage, and grade based on the CBSE grading system.

---

## 📌 Features

- 👨‍🎓 Student Information
  - Student Name
  - Roll Number
  - Class
  - Section

- 📚 Dynamic Subject Input
  - User can enter any number of subjects.
  - Subject names are entered dynamically.

- 📝 Marks Entry
  - Accepts decimal marks.
  - Valid marks range: **0–100**
  - Invalid marks are rejected.

- 📊 Automatic Calculation
  - Total Marks
  - Percentage
  - Overall Grade

- 🏆 CBSE Grading System

| Percentage | Grade |
|------------|-------|
| 91–100 | A1 |
| 81–90 | A2 |
| 71–80 | B1 |
| 61–70 | B2 |
| 51–60 | C1 |
| 41–50 | C2 |
| 33–40 | D |
| Below 33 | Need Improvement / Fail |

- ⚠️ Exception Handling
  - Prevents invalid numeric input.
  - Handles InputMismatchException.
  - Validates Roll Number.
  - Validates Number of Subjects.
  - Validates Subject Marks.

- 🔄 Multiple Report Cards
  - User can generate report cards for multiple students without restarting the program.
